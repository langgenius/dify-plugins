# Privacy Policy for M2MCent Dify Plugin

**Effective Date:** August 19, 2026

## 1. Overview
The M2MCent Gateway plugin connects Dify agents and workflows to specialized external MCP micro-services hosted on pi.m2mcent.com.

## 2. Data Handling
- **No Data Retention:** M2MCent processes function requests in memory and executes AI inference via Gemini 3.7 Flash. No prompt payloads or user inputs are persisted to disk or sold to third parties.
- **Authentication Validation:** Cryptographic authorizations are validated securely against public registries. No private keys are ever collected or stored.
- **HTTPS Encryption:** All communications use TLS 1.3 encryption.

## 3. Contact
For questions regarding privacy, contact support@m2mcent.com or visit https://m2mcent.com.
