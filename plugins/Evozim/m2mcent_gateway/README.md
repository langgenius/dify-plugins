# M2MCent AI Agent Gateway Plugin for Dify

Connect your Dify LLMs, workflows, and autonomous agents to over **1,005 production-ready MCP micro-services** spanning:
- Cybersecurity & Vulnerability Auditing
- Advanced Risk Assessment & Data Analysis
- 3D Geometry, Mesh Optimization & VFX
- Healthcare, BioPharma & Genomics
- Enterprise Compliance & Supply Chain Logistics

## Configuration
1. Install the plugin from Dify Marketplace.
2. Provide your M2MCent Gateway URL (defaults to https://api.m2mcent.com).
3. (Optional) Provide your Access Token or Cryptographic Auth Header for premium endpoints.

## Available Tools
- **search_tools**: Search the 1,005 available micro-services by keyword or domain.
- **execute_tool**: Execute any M2MCent micro-service with automated routing and authentication.
