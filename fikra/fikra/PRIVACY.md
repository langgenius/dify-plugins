# Privacy Policy: Fikra API plugin for Dify

**What this plugin does:** it forwards your Dify model requests (prompts, messages, tool definitions and parameters) to the Fikra API endpoint you configure (by default `https://api.fikraapi.co.ke/v1`) and returns the model's response to Dify.

**What the plugin itself collects or stores:** nothing. It has no database, writes no files, and sends no analytics or telemetry. Your API key is stored by Dify in its encrypted credential store, not by the plugin.

**Data sent to third parties:** your requests go to Fikra API (Lacesse Ventures, Nairobi, Kenya), which routes them to the upstream model provider for the model you chose. How Fikra API handles that data, including retention and zero-data-retention options, is described in Fikra's privacy policy: https://fikraapi.co.ke/privacy
