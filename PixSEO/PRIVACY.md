# Privacy Policy for PixSEO Plugin

**Last updated: July 2026**

## Data Collection

The PixSEO Dify plugin acts as a bridge between the Dify platform and the PixSEO API service. This plugin itself does **not** collect, store, or retain any user data.

### What the PixSEO API processes

When you use this plugin, the following data is transmitted to the PixSEO API at `https://api.hzhdmn.icu`:

1. **Product Images** - Product images you upload (as base64 or URL) are transmitted for background removal and WebP compression only. Images are processed in transient memory and cleared immediately after processing completes.

2. **API Key** - Your PixSEO API Key is transmitted via the `X-API-Key` header for authentication. API Keys are hashed (SHA256) for storage. Usage statistics (request counts) are associated with your API Key for quota management.

3. **Usage Statistics** - We track the number of API calls per API Key solely for quota enforcement and billing purposes.

### What the PixSEO API does NOT process

The following are generated locally by the Agent's LLM (Dify/Coze) and **never** transmitted to the external API:

- **Alt Text** - Generated by the Agent's local LLM
- **Schema (JSON-LD)** - Generated by the Agent's local LLM
- **Listing Copy** - Generated by the Agent's local LLM

### Data Retention

- **Images**: Processed in memory only; **cleared immediately (0 seconds)** after the API response is returned.
- **Text data**: Alt text, Schema, and Listing are generated locally by the Agent — never sent to the external API.
- **API Keys**: Hashed (SHA256) for verification; the raw key is never stored.
- **Usage counts**: Stored as aggregate counters per API Key for quota management.
- **API Logs**: Retained for 30 days — only API Key prefix + timestamp; no image content.

### Third-Party Services

The PixSEO API uses the following third-party service for processing:

- **Photoroom API** - For AI background removal (images are transmitted to Photoroom)

Photoroom does not retain your data for training purposes per their data usage policy.

### Data Security

- All API communication is encrypted via HTTPS (TLS 1.3)
- API Keys are hashed using SHA256 with random salts
- Images are validated (format whitelist, 10MB size limit, Pillow verify) before processing
- `privacy_accepted: true` must be explicitly set in every API request

### User Rights

You have the right to:
- Delete your API Key at any time (via the PixSEO console)
- Request deletion of your usage data
- Contact us for privacy-related inquiries
