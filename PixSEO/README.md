# PixSEO - AI Product Image SEO Optimization

PixSEO is an AI-powered e-commerce image SEO optimization engine. External API handles background removal and WebP compression. Alt text, Schema, and Listing are generated by the Agent's local LLM.

This plugin is free to install and use on Dify. A PixSEO API Key is required to connect to the service.

## Features

- **Background Removal** - AI-powered background removal for clean product images (via Photoroom API)
- **WebP Compression** - Compress images to WebP format for reduced file size
- **Local Alt Text Scoring** - Evaluate alt text quality across four SEO dimensions (length, keywords, natural language, descriptiveness)
- **Privacy Notice** - Transparent data handling: external API only processes images for background removal and compression

## Tools

| Tool | Description |
|------|-------------|
| **Process Product Image** | Remove background and compress to WebP for a single product image |
| **Batch Process Images** | Process multiple product images in batch from URLs or base64 |
| **Query API Usage** | Check current API Key usage statistics and remaining quota |

## Installation

### Prerequisites

- Python 3.12+
- A PixSEO API Key. A free tier with 100 images/month is available. Register at [https://api.hzhdmn.icu](https://api.hzhdmn.icu)

### Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Configure environment:
```bash
cp .env.example .env
# Edit .env and fill in your Dify debug credentials
```

3. Run the plugin:
```bash
python -m main
```

## Configuration

This plugin requires a PixSEO API Key. You can get one by registering at [https://api.hzhdmn.icu](https://api.hzhdmn.icu). A free tier is available for testing.

### Environment Variables

| Variable | Description |
|----------|-------------|
| `INSTALL_METHOD` | Set to `remote` for Dify plugin development |
| `REMOTE_INSTALL_URL` | Dify debug server address |
| `REMOTE_INSTALL_KEY` | Dify debug key |
| `PIXSEO_API_BASE` | Override the API base URL (default: `https://api.hzhdmn.icu`) |
