# 明悉出口管制

一个 Dify 插件，提供中国出口管制清单查询能力，帮助用户判断物项或实体是否受中国出口管制法规约束。

## 功能

- **两用物项查询**：按 ECCN/HS 编码、物项名称或关键词搜索商务部两用物项出口管制清单。
- **受限实体查询**：按公司名称（中英文）搜索中国受限实体名单（管控名单/不可靠实体清单/关注清单/反制清单）。

## 前置条件

1. 明悉 API 密钥，在 [https://mingxiapi.cn](https://mingxiapi.cn) 申请。
2. API 按次计费（每次查询 5 积分），提供免费试用额度。

## 配置

1. 从 Dify 插件市场安装本插件。
2. 打开插件设置，输入明悉 API 密钥。
3. 保存凭证，插件会自动验证密钥有效性。

## 工具

### 1. 查询出口管制物项 (`item_query`)

搜索中国两用物项出口管制清单。

**参数：**
- `keyword`（必填）：ECCN 编码、HS 编码、物项名称或描述。
- `top_k`（可选，默认 5）：最大返回结果数（1-20）。
- `format`（可选，默认 json）：json 返回结构化数据，text 返回可读性摘要。

### 2. 查询受限实体 (`entity_query`)

搜索中国受限实体名单。

**参数：**
- `keyword`（必填）：公司或机构名称，中英文均可。
- `format`（可选，默认 json）：json 返回结构化数据，text 返回可读性摘要。

## 数据来源

所有数据来自中国政府官方公告：
- 商务部出口管制公告
- 外交部反制措施决定
- 通过自动化监控定期更新
