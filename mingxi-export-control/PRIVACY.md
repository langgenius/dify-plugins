# Privacy Policy

## Data We Collect

This plugin processes the following user data:

1. **API Key**: Stored securely by Dify's credential system. Used only to authenticate requests to the MingXi API.
2. **Search Queries**: The keyword the user enters (item code or entity name) is transmitted to the MingXi API to perform the search.
3. **Query Metadata**: IP address, timestamp, and the API endpoint used are logged by the MingXi API for billing and abuse prevention purposes.

## How We Use Data

- **API Key**: Used solely to authenticate and bill API calls. Never shared with third parties.
- **Search Queries**: Processed to return export control search results. Queries may be logged for service improvement and abuse detection.
- **Query Metadata**: Used for billing, rate limiting, and security monitoring.

## Data Retention

- API call logs are retained for billing and security purposes.
- No personal user data beyond the API key and query metadata is stored.

## Third-Party Services

This plugin calls the MingXi API hosted at `https://api.mingxiapi.cn`. By using this plugin, your search queries are sent to this service.

## User Rights

Users may request deletion of their API key and associated usage data by contacting the service provider.

## Contact

For privacy inquiries, contact: support@mingxiapi.cn
