# Privacy Policy

This plugin sends the search query you or your agent enter, plus your Keirolabs API key, to the Keirolabs API (`https://api.keirolabs.cloud`) to run a web search. It sends nothing else.

The plugin itself doesn't store, log or share any data. Your API key is stored by Dify as an encrypted credential.

Keirolabs processes search queries under its own privacy policy: https://keirolabs.cloud/privacy
