# ApocData A-Share Market Data

Zero-auth A-share market data plugin for Dify. 46 tools covering quotes, financials, capital flows, limit-up/down, sectors, announcements, macro indicators and more.

## Features

- **No API Key Required** - All endpoints are free and open
- **46 Tools** - Comprehensive A-share market data coverage
- **Real-time & Historical** - Latest quotes and historical data
- **Zero Dependencies** - Works out of the box

## Tool Categories

| Category | Tools | Description |
|----------|-------|-------------|
| Quotes | quote, stock-bars-daily, stock-bars-weekly | Real-time and historical price data |
| Financials | financial-report, income, balance-sheet, cash-flow | Financial statements and ratios |
| Capital Flow | moneyflow, hk-hold, top10-holders | Capital flow and holder data |
| Limit Events | limit-list, limit-pool, limit-stat | Limit-up/down analysis |
| Sectors | sector-list, sector-flow, sector-detail | Sector/industry analysis |
| Announcements | ann-list, ann-search, ann-detail | Company announcements |
| Macro | macro-latest, macro-history | Macroeconomic indicators |
| Stock Info | stock-list, stock-search, stock-detail | Stock metadata |

## Usage

Simply install and use. No configuration needed.

## Data Source

Data sourced from Tushare and other public A-share data providers.
