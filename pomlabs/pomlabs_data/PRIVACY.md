# Privacy Policy

This plugin sends the parameters you give to each tool (for example a video URL, a username or a search query) and your API key to the Pom Labs Data API (https://pom-data-api.pomlabs.workers.dev) and returns the JSON it answers.

- It reads only public data from the source sites. It does not use your accounts on them.
- The plugin itself stores nothing. The API key is kept by Dify as a credential.
- The Pom Labs API policy is at https://pom-data-api.pomlabs.workers.dev/privacy.
