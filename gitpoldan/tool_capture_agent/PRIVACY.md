# Privacy Policy — Tool-Capture Agent

Tool-Capture Agent is an orchestration strategy that runs entirely inside your Dify
workspace. It does not collect, store, or transmit personal data to the plugin author.

## Data handling

- **Prompts, queries and tool arguments** are passed to the LLM provider and to the
  tools you configure in the Agent node. These are the same providers/tools you have
  already set up in your Dify workspace.
- **Captured tool outputs** are held in memory only for the duration of a single Agent
  node execution and are returned to the workflow as output variables. Nothing is
  persisted by the plugin.
- **No analytics / telemetry**: the plugin performs no tracking and contacts no
  third-party service of its own.

## Third-party services

The plugin itself integrates with no external service. Any data exposure is governed by
the privacy policies of the model provider and tools you select in the node.
